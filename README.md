# Netflix Movie Analysis (1990s)

This project analyzes Netflix movie data from the 1990s using Python and pandas.  

## Overview
- Loaded and cleaned the dataset.  
- Identified the most frequent movie durations.  
- Counted short action movies (<90 minutes).  
- Reinforced practical data analysis skills with a real-world dataset.  

## Tools
- Python
- pandas
- Jupyter Notebook

## Project Files
- `netflix_analysis.ipynb` — main notebook with code and analysis.
